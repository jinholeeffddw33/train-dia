# 2026 추석 특별 다이아 — 만든 과정

`src/data/chuseok2026.ts` 는 이 폴더의 JSON 을 `gen_ts.py` 로 바꾼 결과다.

| 파일 | 내용 | 원본 |
|---|---|---|
| `day_A.json` | 주간 1~34 (9/24~27) | 「추석연휴 주간행로표(1~34)」 한글 그림 |
| `hh_X.json` · `night_A.json` | 야간 69~91 휴휴 (9/24~26) — 열차는 hh_X, 출퇴근은 night_A | 엑셀 그림 · 한글 그림 |
| `link_A.json` | 9/23 저녁 연결시작 62~91 | 캡처 30장 |
| `hp_A.json` | 9/27 저녁 휴평 62~91 (출퇴근은 규칙으로) | 엑셀 그림 |
| `late_A.json` | 심야 1시간 연장 변경·임시 다이아 (9/26·9/27) | 캡처 12장 |
| `xl_summary.json` | 엑셀의 다이아별 근무시간·운전시간·주행키로 | 행로표 시스템 엑셀 4개 |

검증: 서로 다른 그림 두 벌 대조 · 따로 두 번 옮겨 적어 대조 · 엑셀 «운전» 시간과 구간 시간 합 대조(전부 ±2분) ·
전날 야간조의 새벽 열차를 다음 날 누군가 받는지(9/23→9/24 28/28, 9/24→9/25 21/21).
옮겨 적는 규칙은 `TRANSCRIBE.md`, 시각·약호 규칙은 `build.py` 머리말.
원본 한글·엑셀·캡처 파일은 저장소에 넣지 않았다(사업소 배포 자료).
