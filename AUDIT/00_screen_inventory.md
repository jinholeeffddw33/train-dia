# 화면 목록 (Screen Inventory)

## 메인 탭 (6개)
| # | 탭 ID | 탭명 | 페이지 ID | 핵심 기능 |
|---|-------|------|----------|----------|
| 1 | home | 홈 | `pageHome` | 오늘 교번, 시계, 주간 스트립, 내일/모레 카드, 일일팁, 퀴즈 |
| 2 | cal | 교번 | `pageCal` | 월간 달력, 날짜별 상세(교번+시간+행로) |
| 3 | line | 노선 | `pageLine` | 5호선 실시간 열차 위치 (리스트/맵), 브랜치 탭(본선/마천/하남) |
| 4 | cmp | 비교 | `pageCmp` | 2인 교번 비교 (월간 그리드) |
| 5 | contacts | 연락처 | `pageContacts` | 관제+승무운용+신호취급실 전화번호 (tel: 링크) |
| 6 | more | 더보기 | `pageMore` | 설정, 장애알림 관리, SOP |

## 주요 진입 경로
```
앱 시작
  → 스플래시 (1.2s)
  → PWA 미설치 시 → PWA 설치 프롬프트 → 닫기 → 알림 권한 요청
  → PWA 설치됨 → 알림 권한 요청
  → 홈 탭

홈 탭
  ├─ 기관사 미선택 → 빈 카드 + "기관사 선택" 버튼 → 모달
  ├─ 기관사 선택됨 → 오늘 카드 + 주간 스트립 + 상태카드 + 팁/퀴즈
  ├─ 주간 스트립 날짜 클릭 → 미리보기 모드 (해당 날짜 교번)
  └─ 장애 알림 배너 (활성 알림 존재 시)

운전행로 (홈 카드 내)
  ├─ Y자 미니맵 (답십리 중앙, 마천/하남 브랜치)
  ├─ 출발 배너 (4-state: 근무중/종료/대기/준비)
  ├─ 역 차트 (비율 기반 막대)
  └─ 블록별 구간 (1근무/2근무/3근무)
```
