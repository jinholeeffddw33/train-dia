# 행로표 그림 옮겨 적기 — 규칙

각 그림은 서울 5호선 기관사 한 명의 하루 근무(다이아) 한 개를 그린 것이다.
세로 칸은 역, 가로선 하나는 열차 한 편이다. 선 위(또는 선 가운데 말풍선)의 4자리 숫자가 열차번호,
선 양 끝에 붙은 시각이 그 역의 출발·도착 시각이다.

## 그림 형식 두 가지

**A형 (캡처, 파일명 link_… / hh26_… / hp27_…)** — 맨 위 표에 근무명·근무구분·출근시간·퇴근시간.
역 칸(왼쪽→오른쪽):
방화기(=방화기지) 방화역 화곡역 까치산 영등포(=영등포구청) 여의도 마포역 애오개 광화문 왕십리 답십리 군자 강동역 길동역 상일동 둔촌동 마천역 강일 미사 하남검(=하남검단산) 고덕기(=고덕기지)
시각은 초까지 적혀 있다(예 17:45:20). 맨 아래 표에 근무시간(첫 칸)·주행키로(계)가 있을 수 있다(잘려 있으면 null).

**B형 (한글 문서 그림, 파일명 BIN….jpg)** — 왼쪽 칸에 근무번호(가운데 큰 숫자)·출근·퇴근.
역 칸(왼쪽→오른쪽): 방기(=방화기지) 방화 송정 화곡 영구(=영등포구청) 여의 애오 왕십 답십 군자 강동 둔촌 마천 길동 상일 고기(=고덕기지) 강일 미 하풍 하검(=하남검단산)
시각은 분까지. 맨 아래 표: 근무번호, 주행키로 계, 근무시간 계.

**C형 (엑셀 속 그림, 폴더 xl_…/번호.png)** — 파일 이름의 숫자가 곧 근무번호(dia)다. 출근·퇴근·근무시간은 그림에 없으므로
`s`, `e`, `work`, `km` 는 null, `kind` 도 null.
역 칸(왼쪽→오른쪽, 세로 글씨): 방화기지 방화 화곡 까치산 영등포구청 여의도 마포 애오개 광화문 왕십리 답십리 군자 강동 둔촌동 마천 강동 길동 상일동 고덕기지 강일 미사 하남검단산
(강동이 두 번 나온다 — 둘 다 `"강동"` 으로 적으면 된다.) 시각은 분까지.
왼쪽 빨간 «40.6km» 같은 숫자와 오른쪽 빨간 숫자는 무시한다.
**겹줄(═══, 두 줄 평행선)은 편승**이다 — 그 앞 열차의 `next` 를 `"deadhead"` 로 하고, 편승 자체는 trains 에 넣지 않는다.
선 끝의 ○(동그라미) 는 기지 출발 표시다 — `mark: "●"` 로 적는다. ▼ 는 기지 입고.

## 적는 법 — 해석하지 말고 보이는 그대로

열차를 **시간 순서**대로 한 줄씩. 자정을 넘어 아침(예 05:20)에 나오는 열차는 맨 뒤에 둔다.
각 열차마다:
- `train`: 열차번호(4자리 정수)
- `from`: 출발역(위 역 칸 이름을 그대로, 약칭 말고 긴 이름으로: 방화기지/방화/화곡/까치산/영등포구청/여의도/마포/애오개/광화문/왕십리/답십리/군자/강동/길동/상일동/둔촌동/마천/강일/미사/하남검단산/고덕기지/송정)
- `dep`: 출발 시각 문자열 그대로 ("17:45:20" 또는 "07:12")
- `to`: 도착역, `arr`: 도착 시각
- `next`: 이 열차의 끝과 다음 열차의 시작이 **세로 연결선으로 이어져 있으면** `"link"` (같은 전동차로 반대 방향을 이어 모는 것),
  사이에 연결선이 없고 떨어져 있으면 `"break"`, 다음 열차 사이에 점선 «편승» 표시가 있으면 `"deadhead"`, 마지막 열차면 `"end"`.
- 선 끝의 ▼(기지 입고)·●(출발 점) 표시가 있으면 `mark` 에 "▼" 또는 "●".

어느 역 칸인지 헷갈리면 **시각 글자가 아니라 선의 끝점(꺾이는 곳)이 어느 세로 칸 위에 있는지**로 정한다.
그래도 확신이 없으면 `"unsure": "무엇이 불확실한지"` 를 그 열차에 적는다. 추측으로 채우지 말 것.

## 출력

JSON 배열 하나를 지정한 파일에 쓴다(UTF-8). 그림 한 장 = 객체 하나:
```json
{
  "file": "link_62D.jpg",
  "dia": "62D",            // A형: 근무명 칸 그대로 / B형: 근무번호
  "kind": "평휴",           // A형: 근무구분 칸 / B형: null
  "s": "17:15", "e": "08:17",
  "work": "11:08",          // 근무시간 계 (없으면 null)
  "km": 122.2,              // 주행키로 계 (없으면 null)
  "trains": [
    {"train":5655,"from":"답십리","dep":"17:45:20","to":"마천","arr":"18:11:30","next":"link"},
    {"train":5648,"from":"마천","dep":"18:22:00","to":"답십리","arr":"18:48:10","next":"break"}
  ]
}
```
모든 그림을 빠짐없이 적는다. 끝나면 적은 그림 수와, `unsure` 를 단 곳의 목록만 짧게 보고한다.
