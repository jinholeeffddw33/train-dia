# 기준선 문제점 초안 (Baseline Notes)

## 코드 현황
- **app.js**: 2,849줄, 함수 117개
- **style.css**: ~2,250줄, 키프레임 28개
- **data.js**: ~554줄, 스케줄 6테이블(218엔트리), 인원 171명
- **빌드 시스템**: 없음 (vanilla JS, 정적 호스팅)
- **테스트**: 없음 (수동 검증만)
- **도메인**: dia5.kr (GitHub Pages + CNAME)

## 발견된 문제 (우선순위별)

### P0 — 데이터/정합성
1. **CYCLE 배열 정확성 미검증**: 135개 항목이 실제 교번표와 일치하는지 원본 대조 불가 (사용자 아버지가 일부 오류 보고)
2. **공휴일(HOL) 2026년 누락 위험**: 2027까지 데이터 있으나 매년 국무회의 확정 공휴일(대체공휴일 등) 수동 업데이트 필요
3. **`isH()` 토요일 휴일 처리**: 토요일을 무조건 휴일로 간주하는데, 기관사 근무에서 토요일이 실제로 항상 "휴일 스케줄"인지 확인 필요

### P1 — UX/기능
4. **운전행로 차트 역 라벨 겹침**: 역 수가 많을 때 (6+역) 역명이 좁은 공간에 겹칠 가능성
5. **주간 스트립 미리보기 → 오늘 복귀 불편**: 미리보기 모드에서 "오늘로 돌아가기" 버튼이 작음
6. **비교 페이지 비어 있을 때 안내 부족**: 기관사 2명 선택 전 빈 화면
7. **연락처 페이지 flat**: 7개 카드가 세로로 나열, 스크롤 필요
8. **FAB 인라인 스타일 존재**: `style="display:none"` (index.html line 256)
9. **SOP 목록 접근성**: 터치 영역이 텍스트 크기 의존 (44px 미달 가능)

### P2 — 모바일/성능
10. **`user-scalable=no, maximum-scale=1.0`**: 접근성 가이드라인 위반 (확대 차단)
11. **img 태그에 width/height 미지정**: logo.png 레이아웃 시프트 가능
12. **Line5 맵 SVG 성능**: 복잡한 SVG + 열차 위치 렌더링 → 저사양 기기 부담
13. **app.js 2,849줄 단일 파일**: 코드 분할 없음 (vanilla이므로 수용)

### P3 — 코드 품질
14. **console.error 직접 사용** (line 2768): 에러 핸들링 부재
15. **Supabase anon key 코드 노출**: 퍼블릭 앱이므로 RLS 의존 (의도적이지만 기록)
16. **API_KEY 노출**: 서울 열차 API 키 코드에 직접 기록
17. **dead code 가능성**: 미사용 함수/변수 점검 필요
18. **`initDark()`**: `body.dark` → `html.dark`로 이미 변경되어야 하는데 혼재 가능

### P4 — 애니메이션/폴리시
19. **탭 전환 애니메이션**: fadeIn만 있고, 탭 간 명확한 전환감 부족
20. **운전행로 차트**: 정적 — 방향/이동감 표현하는 동적 요소 없음
21. **버튼 프레스 피드백**: 일부 항목만 적용, 통일 안 됨
22. **토스트 위치**: 하단 탭바 위인데, 다른 고정 요소와 겹칠 가능성
