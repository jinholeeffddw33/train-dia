# 교대자 매칭 규칙 (Exchange Partner Matching)

> Train DIA v2 — 교대 상대 탐색 알고리즘 기준 문서
> 최종 수정: 2026-02-28

---

## 1. 기본 원리

교대자 매칭은 **열차 번호 기준**으로 동작한다:

| 방향 | 조건 | 의미 |
|------|------|------|
| **Left (받음)** | 내 구간 첫 열차 = 상대 구간 마지막 열차 | 상대가 운행하던 열차를 내가 인수 |
| **Right (줌)** | 내 구간 마지막 열차 = 상대 구간 첫 열차 | 내가 운행하던 열차를 상대에게 인계 |

---

## 2. 기지 입출고 열차 (교대 없음)

### [P0] 절대 규칙
- **1xxx (1000–1999)**: 기지 출발/입고 열차 — 교대 없음
- **2xxx (2000–2999)**: 기지 입출고 열차 — 교대 없음

### 판별 함수
```typescript
function isDepotTrain(trainNo: number): boolean {
  return trainNo >= 1000 && trainNo < 3000;
}
```

| 열차 | 출현 DIA | 매칭 상대 | 비고 |
|------|----------|-----------|------|
| 2004 | DIA 22 (마지막) | 없음 | 기지 입고 열차 |
| 2006 | 여러 DIA | 없음 | 기지 입출고 |
| 2008 | 여러 DIA | 없음 | 기지 입출고 |

> 2xxx 열차는 어떤 DIA에서도 교대 상대를 가지지 않는다.

---

## 3. 일반 열차 (교대 있음)

- **5xxx (5000–5999)**: 영업 열차 — 교대 매칭 대상
- 같은 열차번호가 한 DIA의 마지막 + 다른 DIA의 첫 열차로 등장하면 교대

---

## 4. 교대 표시 규칙

| 상태 | 표시 |
|------|------|
| 교대 상대 있음 | `교대 ← 이름` 또는 `교대 → 이름` |
| 기지 입출고 (1xxx/2xxx) | 표시 안 함 (교대 없음) |
| 매칭 실패 (5xxx인데 상대 없음) | `교대` (이름 없이) |

---

## 5. 향후 확장 시 주의

- 새로운 열차 번호 대역이 추가될 경우, 해당 대역이 기지 입출고인지 확인 필수
- `isDepotTrain()` 함수 범위 업데이트 필요
- **데이터 파일(`src/data/`)은 절대 수정하지 않음** — 알고리즘으로 해결
