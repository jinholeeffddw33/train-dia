# 실폰 QA 체크리스트 — ZINOSB 8축 이식 (2026-08-09)

> 대상 커밋: `bc9045a` ~ `cbbc650` (축1~7) · 배포 `https://dia5.kr`
> **확인 폭은 두 가지면 충분** — **360px(하한)** / **430px(상한)**. 그 사이는 이 둘이 통과하면 따라온다.
> 특히 **UI 위계와 버튼 줄바꿈**을 본다.
>
> 각 항목은 "무엇을 보고" / "무엇이면 통과"로 적혀 있다. 하나라도 ❌면 그 항목 번호를 알려주면 된다.

## 0. 준비

1. **홈 화면에 추가**로 설치한 PWA 로 연다 (브라우저 탭이 아니라 **설치된 앱**).
   - 왜: 이번 수정의 핵심(노치/다이내믹 아일랜드 방어)이 **설치된 PWA 에서만** 발동한다.
2. 앱을 완전히 종료했다 다시 켠다 (백그라운드 정리).
3. 다크 / 라이트 **양쪽** 으로 한 번씩 본다 (설정 → 화면).

## 10. 아직 안 한 것 (다음 세션 후보)

- **헤더 SSOT 통합** — 13개 화면이 아직 각자 헤더를 그린다(헤더성 블록 192개). 이번엔 **공통 규칙만** 잡고 통합은 안 했다. 통합은 되돌리기 어려운 큰 변경이라 별도 세션이 맞다.
- **백버튼 SSOT · iOS 스와이프 백** — 백/닫기 관련 코드가 83개 파일에 429건 흩어져 있다.
- **개별 버튼 햅틱 배선** — 인터랙티브 요소 703곳. 지금은 토스트 경로만 자동 발화.
- **응답 봉투 전면 전환** — 39개 API 중 1개만 전환. 나머지 323건은 baseline 에 등록해 두고 **새로 유입되는 것만** 차단 중이다.
- **바텀시트 full 높이 노치 클램프 · SW 캐시 갱신 · 공지 실시간 반영 · 저장 회귀 검증** — 추가 요청분, 미착수.
